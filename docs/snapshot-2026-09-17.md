# Snapshot — 17 September 2026

A dated, static copy of what Upstream held, so the evidence stays readable whether or not the live
site or the nightly scrape is working. Nothing here is generated at read time.

- **Data:** [`snapshot-2026-09-17.csv`](snapshot-2026-09-17.csv) — all 753 placed records, 41
  columns, one row each, exactly as `/upstream/export.csv` served them.
- **Taken from:** the live D1 database as the ingest run of `2026-09-17T08:58:42Z` left it.
- **Live equivalent:** <https://rohitrao.in/upstream> and
  <https://rohitrao.in/upstream/about#snapshot>. If those disagree with this file, the live site has
  moved on and this file is the dated record.

## The figures

| Number | As of 17 Sep 2026 | What it counts |
| --- | --- | --- |
| **Sources** | 8 configured, 7 contributing | Scrapers in the pipeline. One of the eight (the NM-ICPS technology hubs list) had put no record on the page by this date, so seven is the number that earned a row. |
| **Records seen** | 2,218 | Distinct records read from those sources, after entries naming the same company were folded together. Not companies: a record can be a research project or a name with nothing behind it. |
| **Placed** | 753 | Records given a row on the page and one of the 44 RDI sub-sectors. These are the only records the page shows. They fall in 36 of the 44 sub-sectors. |
| **Dropped** | 1,465 | Records read but not placed, each kept in the `gaps` table with the reason. Dropped is not rejected: most were too thinly described to classify, not judged uninteresting. |
| **Companies** | 618 | Placed records whose entity type is a company. The other 135 are unverified names, research projects and one laboratory, counted beside the companies and never inside them. |
| **Described** | 525 | Placed records carrying a published sentence saying what they do — 180 quoted from a website confirmed as theirs, 345 from the source that listed them. The remaining 228 have only a register or grant label. |

Placed and dropped account for every record seen (753 + 1,465 = 2,218), and companies for every
record placed (618 + 135 = 753). Described and label-only account for every record placed
(525 + 228 = 753).

## What the CSV does and does not contain

It contains the 753 **placed** records only — the rows the page shows. The 1,465 **dropped**
records are not in it; they live in the `gaps` table, which holds a name and the reason the record
could not be placed, and nothing else worth exporting.

Per row: name, what it builds and whose words that is, website and whether the site was confirmed as
the company's own, founders where a source names them, DPIIT register status, contact, domain
registration date, RDI sector and sub-sector with the classifier's reasoning, tier, public trace
count, and the URL of its page on the live site.

Empty cells are genuinely unknown, not zero. That is the point of the project, and the column is
left empty rather than filled with a guess.

## Regenerating it

```sh
curl -s "https://rohitrao.in/upstream/export.csv?described=all&kind=all&tier=all&age=all&limit=2000" \
  -o docs/snapshot-<date>.csv
```

Then update every field in `src/snapshot.ts`, the table in `README.md`, and this file. The counts
come from:

```sql
SELECT (SELECT COUNT(*) FROM companies)                                          AS placed,
       (SELECT COUNT(*) FROM gaps)                                               AS dropped,
       (SELECT COUNT(*) FROM companies WHERE COALESCE(entity_type,'company')='company') AS companies,
       (SELECT COUNT(*) FROM companies WHERE said_state IN ('own','source'))      AS described,
       (SELECT COUNT(*) FROM companies WHERE said_state='own')                    AS described_own_site,
       (SELECT COUNT(DISTINCT source) FROM signals)                               AS sources_contributing,
       (SELECT value FROM site_state WHERE key='data')                            AS data_version;
```

`snapshotReconciles()` in `src/snapshot.ts` checks the arithmetic, and a test runs it, so a
half-finished edit fails the build rather than the argument.
